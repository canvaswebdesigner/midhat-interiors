# Midhat Interiors

Karachi merkezli bir iç mimarlık markası için hazırlanmış, mobil öncelikli ve dönüşüm odaklı konsept web sitesi.

[Canlı önizlemeyi aç](https://midhat-interiors.canvaswebdesigner.workers.dev/)

## Tasarım odağı

- İç mekân projelerini güçlü bir editoryal akışla sunan premium görsel dil
- Konut, ticari alan ve anahtar teslim uygulama hizmetlerinin anlaşılır biçimde ayrılması
- Proje keşfi, güven oluşturma ve WhatsApp üzerinden teklif isteme akışı
- Telefon, tablet ve masaüstü ekranlara uyumlu responsive arayüz
- Erişilebilir hareket tercihleri ve klavye kullanımını dikkate alan etkileşimler

## Teknoloji

- Next.js App Router ve React
- TypeScript
- Tailwind CSS
- vinext ve Cloudflare Workers

## Yerel geliştirme

Node.js `22.13` veya üzeri gerekir.

```bash
npm install
npm run dev
```

Üretim kontrolü:

```bash
npm test
```

## Yayın

Üretim derlemesi vinext ile hazırlanır ve Cloudflare Workers üzerinde yayınlanır. Bu depo Midhat Interiors için hazırlanmış bir tasarım önizlemesidir; teslim edilmiş müşteri projesi iddiası taşımaz.
